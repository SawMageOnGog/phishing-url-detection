```bash

python -m unittest discover -s tests -v
```

The previous `.venv` is excluded deliberately: it is Mac-specific and should be recreated locally.

## 2. Run cross-validation

Use the completed baseline folder included with the project ZIP. In the provided archive its name was `20261023T021333_607052Z`.

```bash
python validate.py --baseline outputs/20261023T021333_607052Z --folds 3 --model both
```

For a quick first check of the validation process, use `--model logistic`. It runs faster. It is not a substitute for the full model comparison.

The validator uses **only the baseline training partition** for three-fold stratified grouped CV, selecting from two candidates per model by the **mean average precision** across folds. The same predefined 0.5 threshold is used for held-out metrics. It never optimizes parameters on the held-out test partition.

For each model, candidates are the original configuration and one stronger-regularization alternative: Logistic Regression C=1.0 versus C=0.1; Random Forest min_samples_leaf=2 versus 5. These are a deliberately limited search, not exhaustive optimization.
